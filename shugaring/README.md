# Лендинг для мастера шугаринга (Ижевск) — 3 варианта на согласование

Статические страницы на движке StyleNova: один HTML-файл, без сборки, общий `_engine.js`
с календарём записи. Токены, шрифты и структура секций — по образцу `index.html` StyleNova.

| Файл | Вариант | Характер |
|---|---|---|
| `variant-1-karamel.html` | «Карамель» | тёмный шоколад + мёд, крупная типографика, глянцевая карамельная капля |
| `variant-2-pudra.html` | «Пудра» | светлый фарфор + лиловый, антиква Cormorant, редакционная сетка с линейками |
| `variant-3-pop.html` | «Поп» | белый + малина/мята/лимон, жирные контуры, «стикерные» блоки |

## Календарь записи (`_engine.js`)

* 14 дней вперёд, слоты 09:00–18:00, воскресенье — выходной (`SLOTS`, `DAYOFF`, `DAYS_AHEAD`).
* Состояния окна: свободно / занято / прошло; ближайшее свободное считается автоматически.
* Демо-занятость детерминированная (хэш от даты и времени) — календарь всегда выглядит живым.
* **Режим мастера**: кнопка «Я мастер» или `?master` в адресе. Нажатие на время закрывает
  или открывает окно; состояние хранится в `localStorage` этого браузера.
* Заявка: имя, телефон, услуга, комментарий → текст копируется в буфер и открывается ВК.

Ограничение текущей версии: занятость живёт в браузере мастера и не видна клиентам на других
устройствах. Для общей занятости нужен бэкенд или готовый сервис записи (YCLIENTS, Dikidi).

## Что заменить на реальные данные

* `SERVICES` в конце каждого файла — услуги, цены, длительность.
* Блок `#works` — плейсхолдеры под фото из альбомов ВК.
* Отзывы, телефон, адрес, график — отмечены как демо прямо в вёрстке.
* Полоса `.demo` сверху убирается одной строкой после согласования.
