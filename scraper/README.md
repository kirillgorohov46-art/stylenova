# Парсер цен StyleNova (на базе ScrapeGraphAI)

Инструмент для магазина StyleNova: с помощью ИИ вытаскивает со страниц
конкурентов (Авито, Яндекс Маркет и др.) структурированные данные —
**название, цену, состояние, характеристики, наличие** — и складывает их
в один CSV-файл, который удобно открыть в Excel и сравнивать цены.

Под капотом — библиотека [ScrapeGraphAI](https://github.com/ScrapeGraphAI/Scrapegraph-ai):
она сама читает страницу браузером и просит модель OpenAI разобрать её на поля.

---

## Что понадобится (один раз)

1. **Python 3.12 или новее.** Проверьте командой `python --version`
   (на Windows иногда `py --version`). Если версия ниже 3.12 или Python не
   установлен — скачайте с [python.org/downloads](https://www.python.org/downloads/)
   и при установке на Windows **поставьте галочку «Add Python to PATH»**.
2. **Ключ OpenAI.** Заведите его на
   [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
   Это платно, но парсинг на модели `gpt-4o-mini` стоит копейки —
   обычно доли цента за страницу. Пополните баланс в разделе Billing.

## Установка (по шагам)

Откройте терминал (на Windows — «Командную строку» или PowerShell) и перейдите
в эту папку. Например, если репозиторий склонирован в «Документы»:

```bash
cd путь/к/stylenova/scraper
```

Дальше по порядку:

```bash
# 1. Создать изолированное окружение (чтобы не засорять систему)
python -m venv .venv

# 2. Активировать его:
#    Windows (PowerShell):
.venv\Scripts\Activate.ps1
#    Windows (обычная cmd):
#    .venv\Scripts\activate.bat
#    macOS / Linux:
#    source .venv/bin/activate

# 3. Установить библиотеки
pip install -r requirements.txt

# 4. Скачать браузер для чтения страниц (обязательно!)
playwright install
```

> Если на шаге 4 в Windows появится ошибка про браузер — выполните
> `playwright install chromium`.

## Настройка ключа

1. Скопируйте файл `.env.example` в `.env`:
   - macOS / Linux: `cp .env.example .env`
   - Windows: скопируйте файл и переименуйте копию в `.env`
2. Откройте `.env` в блокноте и вставьте свой ключ OpenAI вместо `sk-ваш-...`.
3. Сохраните.

⚠️ **Файл `.env` — это как пароль.** Он уже добавлен в `.gitignore`, поэтому
никогда не попадёт в GitHub. Никому его не пересылайте.

## Как пользоваться

### Вариант 1. Список ссылок (основной режим)

1. Скопируйте `targets.example.json` → `targets.json`.
2. Впишите туда ссылки на товары конкурентов, которые хотите отслеживать:

   ```json
   {
     "targets": [
       { "name": "Ноутбук Lenovo — конкурент А", "url": "https://www.avito.ru/..." },
       { "name": "ПК i5 — конкурент Б",          "url": "https://market.yandex.ru/..." }
     ]
   }
   ```
3. Запустите:

   ```bash
   python scrape_prices.py
   ```

### Вариант 2. Разовая проверка одной ссылки

```bash
python scrape_prices.py --url "https://www.avito.ru/..." "Ноутбук HP"
```

### Результат

После работы появится файл вида `results/prices_2026-09-13_18-30.csv`.
Откройте его в Excel или Google Таблицах — там колонки: дата, название,
цена, состояние, характеристики, наличие, продавец.

## Как изменить, какие данные вытаскивать

Откройте `scrape_prices.py` и отредактируйте текст в переменной
`EXTRACTION_PROMPT` — он написан обычными словами. Например, можно добавить
«гарантия», «год выпуска» и т.п. Модель постарается найти эти поля.

---

## Частые вопросы

- **«command not found: python»** — попробуйте `python3` вместо `python`
  (на Windows — `py`).
- **Ошибка про версию Python** — библиотеке нужен Python **3.12+**.
  Обновите Python.
- **Пустые цены в результате** — некоторые сайты (особенно Авито) активно
  защищаются от автоматического чтения и могут показывать капчу. Тогда
  цена придёт пустой или с ошибкой в колонке `error`. Это ограничение
  любого парсера, а не только этого.
- **Сколько стоит?** Платите только OpenAI за обработку — на `gpt-4o-mini`
  это очень дёшево. Следите за балансом на platform.openai.com.

---

## Юридическая заметка

Собирайте только общедоступные данные и соблюдайте правила использования
сайтов (Авито, Яндекс Маркет и др.) и законодательство. Не создавайте
чрезмерную нагрузку на чужие сайты. Инструмент предназначен для анализа
рынка и ценообразования вашего магазина.
