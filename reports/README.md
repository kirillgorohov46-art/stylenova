# Аналитика цен на комплектующие — StyleNova

Срез рынка на **5 сентября 2026**: цены (новое и б/у) на оперативную память DDR4,
SSD SATA 2.5" и жёсткие диски HDD 3.5" по рынкам России, с референсом зарубежных
площадок.

## Позиции (14)

- **DDR4:** 4, 8, 16, 32 ГБ (модуль DIMM)
- **SSD SATA 2.5":** 128, 240, 512 ГБ, 1 ТБ, 2 ТБ
- **HDD 3.5":** 1, 2, 3, 4, 6 ТБ

Каждая позиция — в состоянии «новое» и «б/у».

## Файлы

- `StyleNova_price_analytics_2026-09-05.pdf` — готовый отчёт (16 страниц: итоги,
  минимальные цены, диапазоны, графики, детализация по позициям, контекст рынка,
  методика и источники).
- `StyleNova_price_analytics_2026-09-05.html` — тот же отчёт в HTML.
- `price_data_2026-09-05.json` — выверенный датасет (минимумы, диапазоны, офферы,
  курс ЦБ, тренды рынка, источники).
- `build/` — скрипты воспроизведения отчёта.
- `StyleNova_china_sourcing_2026-09-05.pdf` / `.html` — расчёт закупки из Китая
  (Alibaba/1688): FOB → себестоимость с ввозом (НДС 22 %, пошлина 0 %) → продажа
  в РФ → наценка, с графиками, механикой ввоза и контролем качества.

## Как пересобрать PDF

```bash
cd reports/build
python3 report.py ../price_data_2026-09-05.json report.html
node html2pdf.js report.html report.pdf report.png   # нужен Chromium/Playwright
```

## Методика (кратко)

Цены собраны из открытых поисковых сниппетов и заголовков карточек площадок
(Яндекс Маркет, DNS, Ситилинк, Ozon, Wildberries, Регард, Никс, E-katalog,
Price.ru, Hardprice и др.). Минимумы новой розницы считались по целевому
форм-фактору (DIMM / 2.5" SATA / 3.5"). Цены б/у — оценка по документированному
дисконту к рознице и агрегированной статистике Авито (прямые листинги Авито из
среды исследования недоступны). Курс валют — ЦБ РФ. Из-за дефицита DRAM/NAND/HDD
2026 года цены волатильны; перед закупкой сверяйте с живой карточкой по ссылке.

Цены ориентировочные, не являются публичной офертой.
