# Анализ по рынку — как повторять

Папка для регулярных срезов рынка по ассортименту StyleNova.
Файлы именуются `ГГГГ-ММ-ДД-market-analysis.md`, каждый следующий сравнивается с предыдущим.

## Порядок проверки

1. **Снять текущий каталог.** Товары лежат в `index.html` в массиве `P` (одна строка, JSON).
   Разобрать без картинок:

   ```bash
   python3 - <<'EOF'
   import json
   line = open('index.html', encoding='utf-8').read().split('const P=')[1]
   data, _ = json.JSONDecoder().raw_decode(line)
   for p in data:
       print(p['id'], p['c'], p['n'], '| цена:', p['p'], '| в наличии:', p['s'])
   EOF
   ```

   Поля: `id`, `c` — категория (`pc`, `trade`, `av`, `office`, `monitor`), `n` — название,
   `br` — бренд, `p` — цена (0 = «Цена по запросу»), `s` — наличие, `sp` — характеристики,
   `d` — описание, `t`/`g` — изображения base64.

2. **Собрать цены рынка по каждой позиции.** Два источника, оба нужны:
   - цена **новой** техники в российских магазинах — задаёт потолок (б/у не может стоить
     дороже 60–65% от новой при живом предложении нового);
   - медиана **живых объявлений** на Авито по Москве при сопоставимой конфигурации — задаёт
     фактическую цену рынка. Ставить свою цену на 5–10% ниже медианы: гарантия 14 дней и
     предпродажная проверка закрывают разницу.

3. **Проверить отраслевой фон:** календарь обязательной маркировки («Честный знак») — он двигает
   спрос на сканеры и торговое оборудование; динамика рынка б/у и новой техники — она двигает
   спрос на компьютеры.

4. **Записать отчёт** по структуре предыдущего файла: главное за день → ограничения данных →
   состав каталога → сегменты с таблицами цен → приоритеты действий → источники.

## Что помечать обязательно

- Откуда цена: **новая** розница или **б/у**. Смешивать нельзя.
- Что измерено, а что рассчитано. Расчётные коридоры помечать как требующие подтверждения.
- Позиции, по которым данных не нашлось, — прямо, а не пропуском.

## Известные ограничения среды

Авито и Яндекс Маркет из рабочей среды Claude недоступны — закрыты сетевой политикой. Медианы
живых объявлений снимаются вручную; список готовых поисковых ссылок есть в конце каждого отчёта.
